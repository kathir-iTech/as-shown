Prompt summaries (not verbatim): generate an original unbranded navy cable-knit sweater flat-lay with a loose stitch near the front hem; generate its corresponding back using that front as a reference; generate an illustrative close-up of its hem detail. Separately generate an ivory silk shirt flat-lay with faint discoloration at the cuff on the viewer's left, its corresponding back, and an illustrative cuff close-up. Neutral product photography, no people, logos, writing, props or watermark. Referenced garment images were the generated designs, not anyone's real photograph.

Source PNGs were converted to JPEG quality 92 without other visual edits. `reference.jpg` and `front.jpg` intentionally use the same original photograph. `prepared.jpg` is a separately recorded orientation/resize/JPEG-88/metadata-removal derivative capped at 2048 px, linked by source digest. Public packages retain all exact source and derivative bytes.

`preview.jpg` in each new folder is the actual YouCam Clothes VTO V3 result on 21 October, with no visual retouching. Navy used the existing fictional female shopper; ivory used the existing fictional male shopper (prepared locally). Each result was exported through the real app and checked against its item, reference, shopper and result digests. Their source condition details are not proof that YouCam preserved or erased any defect.

Two intended tasks used four free units (984 to 980). Valid multipart duplicate replay, recovery and refresh all returned/resumed the same original-session task; no new creation was made for those checks. See [release evidence](RELEASE_EVIDENCE.md). The older linen demonstration and its ledger remain unchanged. Three synthetic examples are not a diverse real-user evaluation.

The UI/CSS and icon are original code. Typography uses the existing self-hosted OFL fonts. No assets or source code from inspiration sites were copied. Generated imagery carries no guarantee of exclusivity or statutory copyright; do not use it to misrepresent an actual garment/person.
